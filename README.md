Telegram Task Planner Bot
Telegram-бот для управления задачами и планами, разработанный на Python с использованием aiogram и SQLite.
Основные возможности
  Создание и управление задачами
  Установка даты и времени выполнения
  Редактирование, перенос и удаление задач
  Отметка задач как выполненных
  Управление планами без установленного срока выполнения
Проект создан для практики разработки Telegram-ботов, работы с базами данных и обработки пользовательских запросов.

Telegram Task Planner Bot
A Telegram bot for managing tasks and plans, built with Python, aiogram, and SQLite.
Key Features
  Create and manage tasks
  Set due dates and times
  Edit, postpone, and delete tasks
  Mark tasks as completed
  Manage plans without deadlines
The project demonstrates practical experience in Python development, database management, and handling user interactions.
